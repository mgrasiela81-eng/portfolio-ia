# 🚀 Portfólio de Projetos de Inteligência Artificial

Este repositório centraliza o meu portfólio de ferramentas e scripts desenvolvidos em Python, focados em automação, inteligência artificial, análise de dados e engenharia de software.

## 📂 Projetos Incluídos

* **`biogen/`** - Ferramenta de análise de dados genómicos e processamento biológico em Python.
* **`assistente/`** - Assistente virtual inteligente com gestão de contexto e estado.
* **`code_evolution/`** - Ferramenta de automação para refatoração e evolução de código com IA.
* **`codigo_atual/`** - Módulos de suporte e scripts correntes de desenvolvimento.
* **`greencode/`** - Analisador de eficiência e métricas de consumo de código sustentável (Green IT).
* **`herbio/`** - Módulos e algoritmos complementares para laboratório e processamento.
* **`memoria_robo/`** - Sistema de armazenamento e persistência de dados estruturados para robótica/assistentes.
* **`organizador_livro/`** - Script utilitário para automação e estruturação de conteúdos textuais.
* **`pyro_guard/`** - Sistema de monitorização de segurança e deteção de anomalias em logs.
* **`techenglish/`** - Ferramenta de suporte técnico e terminologia em inglês para engenharia.

## 🛠️ Tecnologias Utilizadas
* Python
* Linux / Termux
* Git & GitHub
* Automação de Processos & APIs
